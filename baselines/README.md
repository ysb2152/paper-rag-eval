# 회귀 기준선(golden)

회귀 테스트가 비교할 **골든 지표 JSON**을 두는 곳이다.
`runs/`(gitignore로 제외되는 실험 덤프)와 달리 여기 파일은 **커밋**한다 —
"정답지"가 저장소에 있어야 재실행 결과와 자동으로 비교할 수 있기 때문이다.

- 각 JSON은 `config → {hit@5, recall, mrr}`와 `n_questions`를 담는다.
- 값은 손으로 적지 않고 러너의 `--update-baseline`로 찍어서 채운다.
- 판정: 새 값이 골든보다 허용치(0.01)를 넘게 **하락하면** 실패. 상승은 통과(의도한 개선이면 갱신).
